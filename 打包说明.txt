一、包内有什么
qilin_island/        程序源码（app / core / modules / services / infra / platform 五层）
resources/           图标与图片资源（logo、图钉 SVG、勾选与箭头 PNG）
tests/test_smoke.py  离线自检脚本，共 334 项断言
packaging/           build_deb.sh 打包脚本 + 桌面启动项
README.md            1.2.9 起逐版本的改动记录（含每一处改动的实测数字）
原源码说明.txt       这份源码的来源说明

二、包内没有刻意排除的东西
dist/                构建产物（16 个 .deb，约 1.9MB），源码包不需要，已排除
__pycache__/ *.pyc   Python 编译缓存，已排除

三、运行环境（零第三方依赖，完全离线）
系统：麒麟 UKUI V10
Python：3.8.10
Qt 绑定：PyQt5 5.14.1（Qt 5.12.8）
除 PyQt5 外不 import 任何第三方库。

四、怎么跑起来
cd 解压目录/麒麟灵动岛-1.4.15-源码
python3 -m qilin_island

五、怎么自检（不碰真实用户数据）
FUYU_HOME=$(mktemp -d) QT_QPA_PLATFORM=offscreen python3 tests/test_smoke.py
预期：334 项 ok、0 项 FAIL、最后一行「自检通过」。
FUYU_HOME 指到临时目录是为了不写 ~/.config/fuyu/data.json。

六、怎么打包安装
bash packaging/build_deb.sh
产物写在源码根目录的 dist/ 下（脚本里 OUT=${SRC}/dist），即
dist/麒麟灵动岛_1.4.15_all.deb；脚本内含三道护栏（README 有本版改动段、
control 描述有本版条目、README_MD5_EXPECT 与 README.md 实际 md5 相符）。
sudo dpkg -i dist/麒麟灵动岛_1.4.15_all.deb
build_deb.sh 生成的 deb 内没有 prerm/postrm 删除用户数据的脚本，
卸载（sudo dpkg -r qilin-island）只移除程序文件与自启项，
不动 ~/.config/fuyu/data.json，也不动源码目录。

# 麒麟灵动岛 1.2.9 重构版

代码按《20261116 麒麟灵动岛 · 开发方案》的五层十七模块组织，1.2.8 完成与原版
的等价性对齐，1.2.9 按用户试用反馈改了八处行为。原版源码在
`/home/Admin/桌面/麒麟灵动岛-1.2.8-源码/`，未改动。

## 1.2.9 改动（对应用户反馈 8 条）

1. **折叠尺寸太小** → 折叠胶囊宽度不再按内容现算，恒等于隐藏横线的 `LINE_W = 200`。
2. **专注倒计时进度条** → 收起态胶囊底部那条细进度（横版、刘海版、侧边竖版）全部去掉，
   专注照常后台计时，展开页里的环形进度保留。
3. **周边白色锯齿** → 无合成器时先用同一份渐变铺满矩形再画圆角面板（1.2.8 的抗锯齿
   边缘混到了窗口默认的浅色底上，就是那圈白），遮罩也改成逐行像素区域，
   不再用 `toFillPolygon()` 的粗折线。
4. **右侧四个蓝点** → 那是音乐均衡条静止的样子；现在只有真的在播放时才出现。
5. **隐藏→折叠动画不顺** → 宽度固定后只剩纵向变化，展开改 240ms `OutQuint`、
   收起 170ms `OutCubic`，动画期间冻结轮播重排。
6. **隐藏方式** → 取消「全屏自动隐藏」和「最大化缩成细线」两个自动行为，设置面板里
   相应两项一并去掉；隐藏只有一个入口：托盘右键「隐藏成横线」（胶囊右键、关窗同义）。
   横线状态悬停或点一下先回到折叠胶囊，再悬停才展开面板。
7. **置物架** → 改名「文件中转站」（导航页签、通知、右键菜单、包描述同步）。
8. **折叠大小忽大忽小** → 与第 1 条同一处修改：`_collapsed_size()` 只返回常量，
   `_reflow()` 及其宽度签名一起删除。

`data.json` 只增不改：新增 `hidden`，`fullscreen_hide` / `maxline` 保留字段但不再读取。

## 1.4.15 改动（日历页铺满纵向空间：空日程日不再有 48px 死白，网格行高 23.7→29.7）

用户口径（2026-11-22 截图 23-10-28）：「日历这一块，下面还是有空白的地方。把上面整体日历
的间距拉大一点，尽量能够在这个界面铺满。」

数出来的账（面板 378×348；页面容器 354×267，日历页上下边距 2/8 ⇒ 可用高 257）：

- 那块空白不是边距，是**当天 0 条日程时仍然占位的日程列表**。它无边框、底色透明，
  旧代码写 `setMinimumHeight(40)` + `setMaximumHeight(88)` + stretch 2，一条都没有时
  照样占 40px，再叠一格 4px 间距——截图里 y≈286..333 那 48px 就是它，与"内容列对齐"无关。
- 顺带结掉 1.3.3 遗留的「日历页纵向挤压」（台账 #24）：可用 257 减去月份行 22、按钮行 31、
  3 格间距 12，只剩 192 给「网格 + 列表」，而旧的两个下限加起来是 160 + 40 = 200 > 192，
  布局压不下去就在网格与按钮行之间叠了 4px。这条以前只在页面上看着"挤"，量出来是重叠。
- 改法把这本账写成两个常量（`modules/calendar.py` 顶部，注释里带完整算式）：
  `GRID_MIN_H = 144`、`EV_LIST_H = 48`，144 + 48 = 192 正好闭合；列表改成定高、
  当天 0 条时 `setVisible(False)` 整条收起，网格 stretch 3→1 吃掉全部余量。
- 空日程日（用户现在这个状态）：网格 160→**196**，每行 (196−18)/6 = **29.67px**
  （改前 23.67，+6.0px/行），网格面板 y 从 99..259 变成 99..295，按钮行随之落到
  面板 y 299..330，下面只剩页面下边距 8 + body 下边距 10 = 18px，与其它页一致。
- 当天有日程：列表可见、定高 48，行高实测 21 ⇒ 正好两行，第三条起走滚动条；
  网格压到下限 144，每行 21.00px。两种状态实测重叠都是 **0px**。
- 一处代价说清楚：点到一个有日程的日子，列表出现、网格会缩 52px（行高 29.67→21.00），
  按钮行上移 52px。这是"空日程日铺满"的必然结果；不改回死白。
- 字号随格子抬一档：日期数字 10→**11px**（星期表头仍 9px）。30px 高的格子里再放 10px
  数字会显空，这一处是跟着行高走的配套，不是新加视觉元素。
- 没动的：水平内容列（日历页仍 12..365，1.4.14 那条逐页守护照旧通过）、月份行 22px、
  按钮行 31px、页面上下边距 2/8、星期表头 18px、选中/今天的画法、日程数据结构。
  `data.json` 无新增键，events 一位没动。
- 新增一条读屏名：日程列表 `accessibleName = "当天日程列表"`——它现在会整条消失，
  读屏得知道那块出现过的是什么。

自检 334 项 0 FAIL（1.4.14 的 315 项 + 本条 19 项：账本闭合 1、可用高基准 1、条目数 1、
读屏名 1、字号 1、有日程态 5、空日程态 4、改前重建 2、参数装回与数据清场 2）。
改前那两个数不是回忆：自检里把旧参数（网格下限 160、列表 min40/max88、stretch 3/2、

- **删除带撤销**：Toast 新增可点右侧动作区（`show_text(..., action=("撤销", fn))`），
  删除后 5 秒内可撤销，`store.restore_todo` 原样放回、id 不变。
- **日历重复**：EventDialog 加「重复」行（不重复/每天/工作日/每周/每月）；
  `store.add_event(..., repeat=)` 写入 repeat 键，旧记录无此键一律 `.get(...,0)`；

## 1.4.3 改动（收起胶囊内图标与内容对齐）

用户口径：① 图标与内容中心对齐；② 图标靠左侧；③ 时间和内容占「没有图标那块的
中心」，而不是整个胶囊的中心。

- `core/pill.py`：`_axis` 不再是「岛体中轴折算进控件」，而是
  `宽度/2 - LEAD/2`（LEAD = 头部布局 spacing），即从图标右沿到右侧内边距这段
  自由区的中心；`resizeEvent` 里同步刷新，窗口尺寸变、右侧控件显隐都不会再偏。
  静止页 clamp 收成 `[0, 宽度-墨迹宽]`，左侧贴 0 即图标右沿，天然压不到图标。
- `LogoLabel`：新增墨迹测量，画时抵消 pixmap 自身的透明边，图标墨迹贴住左内边距。
- `VDY` 3.0 → 2.5：文字墨迹中线与图标墨迹中线严格重合（文字走整数基线，实测
  0.5px 内）。
- 自检新增 4 项守护：居中基准=自由区中心、不再是岛体中轴、图标贴左内边距、
  图标与文字墨迹中线重合；旧断言「文字居中基准是岛体中轴」按新口径替换。

|---|---|---|---|

## 1.4.2 改动（未展开态边缘锯齿）

根因不在绘制，在判定：`platform/x11.py` 用 `xprop -root _NET_WM_CM_S0` 问有没有合成器，
而 EWMH 的口径是 `_NET_WM_CM_S<n>` 这个 X selection 的属主——合成器只声明 selection，
从不往 root 写属性。本机 ukui-kwin_x11 一直在跑，却被一路判成"无合成器"，岛体走
1-bit 窗口遮罩，圆角只能是整像素台阶。

- `has_compositor()` 改为 ctypes 直查 `_NET_WM_CM_S<n>` selection 属主（逐屏问），
  `xprop` 只留作 libX11 加载不了时的保守兜底；`FUYU_COMPOSITE=0/1` 对照开关保留。
- 面板 `alpha` 由 246 改回 255：合成器一开就是 4% 透底，正文笔画从深色底里浮出来，
  小字号对比度跟着掉。平滑边缘来自圆角路径自身的像素覆盖率，与整体 alpha 无关。
- 提示条在有合成器时 `clearMask()`：遮罩压在抗锯齿绘制上等于把画顺的圆弧重新切成台阶。

验收口径（同一屏幕、同一时刻、两种绘制路径各截一次，数边界行的最大单步亮度跳变）：
遮罩路径平均 154.7、最陡 202、平滑行 8/80（10%）；修复后平均 96.6、最陡 165、
平滑行 53/80（66%）。安装后的实机数值与之一致。

```bash
PYTHONPATH=. /usr/bin/python3 -m qilin_island          # 启动
PYTHONPATH=. /usr/bin/python3 -m qilin_island --quit   # 通知在跑的实例退出
python3 tests/test_smoke.py                            # 离线自检（不需要 X）
```

其余图标由 `core/brand.py` 现画，不引用第三方素材。SVG 素材（`pushpin.svg`）由
`infra/svgpath.py` 自己解析成 `QPainterPath`——本机 `import PyQt5.QtSvg` 直接
ModuleNotFoundError，装 QtSvg 会破坏零依赖，所以不引。

## 打包与安装

```bash
bash packaging/build_deb.sh                      # 出 dist/麒麟灵动岛_<版本>_all.deb
sudo dpkg -i dist/麒麟灵动岛_1.2.8_all.deb        # 安装，入口 /usr/bin/qilin-island
sudo dpkg -r qilin-island                        # 卸载
```

包名 `qilin-island`，代码装到 `/usr/lib/qilin-island/qilin_island`，素材必须同级放在
`/usr/lib/qilin-island/resources/assets`（`infra/paths.py` 按 `<项目根>/resources/assets` 找），
桌面条目和图标随包走。三点要注意：

- 与系统里已装的 `fuyu` 包并存，互不覆盖文件；但两者共用 `fuyu-instance` 套接字和
  `~/.config/fuyu`，同一时刻只能有一个在跑，后启动的那个只会唤醒已运行的那个。
- 设置里勾选「开机自动启动」写出的条目仍是 `Exec=fuyu`（1.2.8 原行为，由 APP_ID 派生）。
  要让开机自启跑重构版，要么把 `~/.config/autostart/fuyu.desktop` 的 Exec 改成
  `qilin-island`，要么改 `services/autostart.py` 让 Exec 跟 launcher 名一致——后者属于行为改动。
- `/usr/lib/qilin-island` 属 root，普通用户运行不会在里面留下 `__pycache__`。

## 表 10 事件契约怎么落地

没有引入装饰性的 EventBus——同步调用顺序就是 1.2.8 的时序，加总线只会打乱它。契约用三样东西表达：

1. **host 门面**（`app/island.py`）：页面只通过 `self.host` 的六个成员碰窗口
   （`settings` / `notify()` / `set_clipboard()` / `ext_drag()` / `recenter()` / `store`），
   页面里不出现窗口内部状态。
2. **Page 接口**（`modules/base.py`）：`on_show()` / `tick(now)` / `refresh()` /
   `capabilities`，心跳由 `core/content.py::_tick` 单向驱动，页面之间不互相调用。
3. **能力注册表**（`app/island.py::_build_pages` + `provider(name)`）：跨页找对方只走
   `self.provider("media")` 这类名字查询，取代原版按类名扫描 pages 列表的写法。

## 加一个功能页

1. `modules/xxx.py` 里 `class XxxPage(Page): capabilities = ("xxx",)`，实现 `on_show/tick`。
2. `modules/__init__.py` 的 `PAGE_CLASSES` 末尾追加一项（顺序即导航顺序，只追加不插入）。
3. 需要落盘就在 `infra/store.py` 加读写方法，沿用 `data.json` 现有结构，别新建文件。
4. 收起态要露信息，就在 `core/content.py::_car_build_pages` 的队列里插一条。
5. 页面布局的水平边距一律取 `core/consts.py::CONTENT_PAD_X`（1.4.14 起为 0），别自己写
   数字：内容列的左右缘只由 `app/island.py` 里 body 的 12px 边距决定，页面再叠一层水平
   边距就会比页签卡缩进一截（自检有逐页 12..365 那条守着）。

## 不能动的兼容性红线

- `APP_ID = "fuyu"`：配置目录 `~/.config/fuyu`、IPC 名 `fuyu-instance`、锁
  `/tmp/fuyu-lite.lock`、自启条目 `fuyu.desktop` 都由它派生，改了老用户的设置和自启就丢
  （`meta.py`）。
- `data.json` 的字段结构（`infra/config.py::DEFAULT_SETTINGS`）：只加不改不删。
- 启动顺序：建 QApplication → 单实例探测 → 锁 → 图标 → 建岛 → 起 IPC → `prepare_taskbar()`
  → `show()`。`prepare_taskbar()` 必须在 `show()` 之前，否则 UKUI 底栏会占位
  （`app/bootstrap.py`）。
- 无合成器时走 1-bit `setMask`，有合成器才用透明图层（`core/shape.py`）。
